Week 5 - Data Visualization

Description

This project is about **Healthcare Data Analysis and Visualization using Python**.

Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn

Dataset

Healthcare Dataset

Work Done

* Load the dataset
* Check rows and columns
* Check missing values
* Convert date columns
* Analyze admission types
* Analyze billing amount
* Create visualizations

How to Run

1. Open the Jupyter Notebook.
2. Upload the healthcare dataset.
3. Run all the cells.
4. View the results and graphs.

Conclusion

This project helps to understand **healthcare data using Python and graphs**.
